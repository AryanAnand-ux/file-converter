# Project Overview: ConvertIO

ConvertIO is a client-side file conversion and PDF utility application. It is designed to run entirely in the browser, eliminating the need for server-side processing, file storage, or data retention.

## Core Value Proposition
- **100% Client-Side Processing**: Zero server costs, infinite scalability, and total privacy for sensitive files.
- **Speed**: No uploading or downloading wait times. Files are read and processed instantly in RAM.
- **Rich Accents**: Styled with Tailwind CSS v4, supporting clean light theme aesthetics with subtle card glows and transition animations.
